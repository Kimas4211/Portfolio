# MAGE_01 — 法师角色建模设定 v0.1

> 项目：BEYOND THE CLASS · Portfolio  
> 所属阶段：Stage 02 — 首个 Blender 角色视觉锚点  
> 状态：**设计提案 / 未最终定稿**。本文件用于统一视觉和技术方向，不代表已经完成建模。

## 01. 核心定位

**角色名（暂定）：裂隙观测者 / The Rift Observer**  
**职业：Mage / 法师**  
**代表能力：AI 辅助设计、AI 原型、创新实验、智能工作流**  
**一句话设计命题：用奥术将混沌问题拆解成可理解、可创造的结构。**

角色必须属于原始参考图的黑暗奇幻世界。不可做成纯科幻机甲、赛博朋克黑客、银行品牌吉祥物或普通蓝色发光袍子。AI 是其“魔法逻辑”，而不是把现实 AI logo 贴在服装上。

关键词：古典奥术 / 克制的智慧 / 结构化思考 / 半写实材质 / 冷蓝与炽红对比。

## 02. 两个观看距离是设计硬约束

**远景（首页五人小队）：** 法师可能只占画面高度的一小部分。必须靠轮廓识别：高于头顶的法杖、偏斜的长披肩、袖口与衣摆的三角负形、略侧身的站姿。默认状态不依靠面部、花纹或小字辨识。

**近景（Hover 聚焦）：** 同一模型逐渐亮起，显示清晰的兜帽边缘、脸部、肩部结构、腰带、布料与金属材质，以及少量几何奥术符文。不要替换成另一张造型不同的角色图片。

## 03. 造型：一个主方向，不同时开发多个风格

### 3.1 比例与姿态
- 成年、中性气质；身形修长、稳定，不要大肩甲和超宽盔甲。
- Blender 建模身高基准 **1.80 m**（只是统一比例的工作值）；法杖约 **2.05–2.20 m**。
- 站姿是对峙巨龙时的警戒姿态，不是摆拍：重心落在后脚，肩部轻微转向巨龙，头部朝上。
- 法杖占据身体一侧，形成远景最明显的垂直轮廓；法杖尖端略超出头部。另一手保留施法空间。
- 三个识别节点：**细高法杖尖端、非对称披肩、分叉长袍下摆**。

### 3.2 头部
- 有兜帽，但兜帽不能完全吞没脸：悬停时可看见鼻梁、下颌与眼部光线。
- 不用传统尖顶巫师帽，也不做硬质科技头盔。
- 面部细节不是远景识别重点；中景以冷静、自信而非凶恶的神态为主。

### 3.3 服装结构（从大到小）
1. **内层**：贴身深色高领衣与收束的袖口，负责舒适的骨骼动作和轻盈体态。
2. **中层**：深蓝灰长袍，腰间以皮革束带分隔上、下半身；袍摆分叉，露出腿部与靴子。
3. **外层**：仅一侧更长的厚披肩，边缘磨损克制；在剪影中形成不对称三角轮廓。
4. **少量硬质细节**：肩部与腕部有古典金属扣件。装饰不能变成密密麻麻的线条或满身发光管。

### 3.4 法杖
- **主要视觉锚点**，比头饰和服装花纹更重要。
- 杖身是深色木/氧化金属的复合结构，主体偏细但不能细到远景消失。
- 顶端用一个**开口的圆弧 + 中央悬浮菱形晶核**构成；外轮廓需在剪影中成立，不做复杂同心圆堆叠。
- 默认：晶核几乎不发光。Hover：一条冷蓝的核心光线点亮。Cast：菱形分解为少量几何切面，形成施法焦点。
- 不要使用明显 Wi‑Fi、二维码、通用机器人头像等现实科技图标。

## 04. 配色与材质

| 部位 | 建议色 | Hex | 材质 |
|---|---|---|---|
| 长袍主布料 | 深海军蓝 | `#17263B` | 高粗糙度厚布，极弱反射 |
| 内衬与兜帽阴影 | 煤黑蓝 | `#101720` | 哑光织物 |
| 皮革束带/靴子 | 石墨灰 | `#343E46` | 旧皮革 |
| 金属扣件与法杖结构 | 暗旧金 | `#9F8662` | 磨损金属，非镜面金 |
| 觉醒/施法核心 | 奥术蓝 | `#57B9F3` | 低面积、高亮度发光 |
| 二级符文高光 | 冷灰白 | `#D5E6F2` | 局部光纹 |

**环境整合：** 原始巨龙背景为强烈红橙色。人物默认受到后方红橙色轮廓光，身体正面仍较暗；Hover 后增加局部冷蓝色光，**保留红橙环境反射**。不能把角色照成脱离场景的蓝色宣传人像。

**发光限制：** 默认无大面积常亮蓝光；Hover 只点亮法杖晶核、袖口少量符文和眼部一点反光；Cast 才允许短时间明显增强。不要整件袍子像霓虹灯一样发光。

## 05. 三个画面状态 + 动作

| 状态 | 时长建议 | 角色动画 | 网页反馈 |
|---|---|---|---|
| Idle / 剪影待机 | 4–6 秒循环 | 缓慢呼吸、披肩小幅摆动、稳稳握杖 | 暗剪影 + 红色轮廓光；无自动大动作 |
| Awake / 悬停觉醒 | 0.45–0.7 秒 | 轻抬头、法杖抬起少许、空手缓慢张开 | 材质显色，蓝色核心点亮；相机轻微推进但不改变构图中心 |
| Cast / 点击施法 | 1.1–1.6 秒 | 杖尖聚能、手臂引导、向前释放 | 蓝色奥术束流扩展至画面，融合进魔法书出现 |
| Return / 未触发离开 | 0.35–0.6 秒 | 恢复警戒姿态 | 渐暗至剪影，镜头柔和归位 |

**关键交互原则：** Hover 动画能随时逆向取消；快速扫过人物时不能触发完整施法。Cast 只由明确点击触发。用户启用“减少动态效果”时直接进入魔法书，避免强闪光。

### 施法节奏（建议标记点）
- 00–25%：杖尖晶核亮起，几片奥术符文沿法杖形成。
- 25–55%：法师挥杖，短暂蓄能，能量只在上半身附近聚集。
- 55–85%：一束集中而有穿透感的蓝色光向镜头方向释放；不长时间遮挡全部内容。
- 85–100%：光束展宽变为书页边缘的光线，**转场出现魔法书**。

网页端处理画面级光束、少量粒子和 UI 过场；Blender 动画负责人物、武器姿态与关键时间点。不要在 Blender 中把整块网页 UI 渲成纹理。

## 06. 镜头与角色站位

- 首页沿用原始参考图的构图原则：**巨龙巨大，五人小队很小**，不要为了看清人物而牺牲体量对比。
- 法师建议站在小队中心偏左；实际坐标在五人全体 Blockout 时再敲定。
- Hover 相机仅轻微偏移/推进；仍应保留巨龙的面部与其压迫性。用户鼠标离开后顺滑归位。
- 点击时先突出角色 3D 动作，再用网页特效接到 UI。**不必做近距离 360° 旋转镜头**。
- 点击区域可大于可见模型，但五个职业不得互相覆盖导致误选。

## 07. Blender 模型制作与网页导出

**首版实时资产目标（供测试，不是硬性的性能保证）：**
- 单英雄约 **10k–18k triangles**，重点分配在头部、披肩外轮廓、杖尖与手部。
- 优先 1 组共享的 1K–2K 贴图图集；需要近景展示再升级分辨率。
- 适合 glTF PBR 的基础色、金属度、粗糙度、法线及必要的 Emissive；避免依赖 Blender 专属节点。
- 披肩以骨骼动画或少量控制骨驱动，网页端不强制实时布料物理。
- 最初就规划 **Idle / Awake / Cast** 三段独立 Action，命名稳定，网页容易调用。
- 角色、法杖同一个逻辑资产导出；保证固定原点和缩放，避免网页每次重新对齐。
- 先从 Blender 输出 `mage_blockout.glb`，在网页中验证剪影、尺寸与性能，随后再细化贴图与骨骼。

**推荐工作结构：**
```text
assets/
  blender/
    hero_mage.blend
  models/
    mage_blockout.glb
    mage_final.glb
docs/
  characters/
    mage.md
```

## 08. 制作先后顺序与验收点

**Gate A — 只有剪影的 Blockout（必须最先通过）**
- 正面、45°、背面三视角的灰模/黑模截图。
- 缩到首页实际显示尺寸后，仍能靠杖尖与不对称披肩识别法师。
- 五人同场时法师和术士不会混淆。
- 动作站得住、脚底接触岩石平台，没有悬空。
- 在橙红背景前看起来属于场景，而非粘贴上去的单独立绘。

**Gate B — 材质和打光**
- 保持原场景的红色环境反射，局部增加冷蓝亮点。
- 默认、Hover 两种状态的轮廓与重点足够分明。
- 金属/布料/皮革分得清，但没有过量小装饰。

**Gate C — 动画和网页**
- 三段动画导出后，网页可以切换并自然中断 Hover。
- 光束不会造成长时间全屏闪烁；能稳定衔接到魔法书。
- 常见桌面视口和移动端降级展示都不阻碍进入真实作品。

## 09. 明确不做

- 不做“满身赛博线条 + 外骨骼装甲”的科幻法师。
- 不做几十个浮动环、漂浮屏幕和数据方框。
- 不用全程蓝光覆盖原图的红色龙穴氛围。
- 不先制作高精度皮肤、复杂毛发、真实布料模拟。
- 不先建五个角色、也不同时制作五套技能书。
- 不把模型设计成只能在 Blender 渲染、网页无法保持材质的效果。

## 10. 下一轮需要确认的唯一视觉问题

在投入精细建模前，**先确认法师的黑色轮廓和法杖顶部造型是否足够鲜明**。确认后才进入正式三视图、材质细化和骨骼。此文档是 v0.1 方向稿，视觉尚未锁定。
