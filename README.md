# BEYOND FORM. / KIMAS.

Interactive portfolio with five sculpture regions: MIND, SIGNAL, CORE, FORM and IMPACT.

## Hosting

GitHub Pages publishes the root of main at https://kimas4211.github.io/Portfolio/.
This is a buildless static site. Serve this directory over HTTP for local development.
All models, videos and stills are referenced with repository-relative URLs.
Three.js 0.170.0 is loaded from jsDelivr through the existing import map.

## Assets

The David scan attribution and CC BY-SA 4.0 license are displayed on the website.
The runtime model is assets/models/david-v2.glb.
The five video transitions and final stills are stored in assets/.
